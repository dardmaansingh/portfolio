# Portfolio

Personal portfolio website showcasing my projects, skills, and competitive programming achievements.

🚀 Deployed: https://personal-portfolio-beryl-five-75.vercel.app/

⚡ Tech Stack

* Framework: React (Vite SPA)
* Styling: Tailwind CSS v4
* Animations: motion/react
* Icons: Lucide React

🌟 Features

* Dark/Light theme support (flicker-free load)
* Infinite floating portrait animation
* Interactive stats dashboard (CP achievements)
* Click-to-copy contact rails
* Fully responsive layout (mobile, tablet, desktop)
